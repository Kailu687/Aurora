Prefer a browser? Open the web app. Want the source? View it on GitHub. Aurora is MIT licensed.

Installing on Android

  1. Download the APK above and open it. If Android asks, allow your browser (or Files app) to install apps from this source.
  2. Open Aurora, tap Add music, choose your music folder, then Use this folder and Allow. Songs show up straight away and covers fill in.
  3. Allow notifications when asked, so the player appears in the notification bar and lock screen.
  4. Updating: Aurora offers updates by itself. To install a new APK manually, install it over the old one and do not uninstall first.

Installing on Windows

  1. Download the installer and run it. Choose where to install.
  2. If Windows SmartScreen says “unknown publisher”, choose More info, then Run anyway. (The installer is not code-signed yet. Check the checksum below if you want certainty.)
  3. Open Aurora, click Add music, and pick your music folder. It stays linked, nothing is copied.

Verify your download

Each release lists the SHA-256 checksum of its files. After downloading, compare it with your file. On Windows, open PowerShell in the download folder:

Get-FileHash .\Aurora.apk -Algorithm SHA256

If the value matches the one shown here, the file is exactly what was published. The Android app is also signed with the Aurora release key; Android only lets a signed update replace an installed Aurora if it carries the same signature.
